# ぴかり（No.4・でんき）画像生成プロンプト

他の生成AIへ渡す用。**3形態ぶんを1枚ずつ、別々に生成**する。

## 出来上がりの条件（ここを外すと取り込めない）

- **2048 × 2048 の正方形・PNG**
- **背景は完全な透明（アルファ0）。**透明を表す市松模様（グレーの格子）を
  画像として描き込まないこと。**過去に一度これで作り直しになった**
- **1枚に1体・1形態だけ。**複数形態を並べた比較図にしない
- 影・グロー・光の粒などのエフェクトも透明背景の上に描く（背景色で塗り込めない）
- **署名・ウォーターマーク・ロゴ・文字を入れない。**画面の隅の小さなマークも不可
- キャラは枠の中央、フレームの高さの **65〜75%** に収める（四辺に余白を残す。
  取り込み時に自動で切り出して512pxに縮小するため、端に触れると切れる）

ファイル名（`incoming-art/` に置く）:

```
pikari-1.png  … 第1形態
pikari-2.png  … 第2形態
pikari-3.png  … 第3形態
```

## 絵柄（既存3体と揃えるための指定）

すでに「ひのこ（ほのお）」「しずく（みず）」「はっぱ（くさ）」の3体が同じ絵柄で
作られている。**同じシリーズに見えることが最優先。**

- 子供向けのモンスター育成ゲーム風。かわいく、親しみやすく、怖くない
- **輪郭線は太めのはっきりした線。**線の色は黒ではなく、そのキャラの色を
  暗くした色（しずくは紺、はっぱは深緑）。ぴかりなら **濃い琥珀色〜こげ茶寄りの暗い黄土色**
- 塗りはセルシェーディング（2〜3階調）＋やわらかいグラデーション。
  つやのハイライトを入れる。光は**左上から**
- **おなかから胸にかけて、クリーム色（アイボリー）の淡い面**を入れる。
  3体すべてに共通している特徴なので必ず入れる
- 目は大きくシンプル。やさしい笑顔。口は小さく
- まわりに元素のモチーフを少し浮かべる（しずくは水滴と泡ときらめき）。
  ぴかりなら **小さな稲妻・火花・光の粒**
- 正面向き（わずかに斜め）で全身。ポーズは落ち着いたもの。
  ホーム画面では90〜200pxに縮小されるので、シルエットで分かる形にする

## キャラクター設定

- 名前: **ぴかり**
- タイプ: **でんき**
- 基本色: **#ffd23d（あざやかな電気の黄色）**
- 図鑑の説明: 「いっしゅんの すばやさは だれにも まけない。ボールを おとさない
  しゅんぱつりょくを もつ。」
- とくせい「いなずま」: ノーバウンドのEXPが1.5倍
- 性格: 瞬発力の塊。とにかく速い。じっとしていられない元気な子。
  リフティングでボールを落とさない反射神経が持ち味

## 第1形態（`pikari-1.png`）

**いちばん小さくて丸い、赤ちゃんのような姿。**

- 丸い体にちょこんと手足。頭は体と同じくらい大きい（2〜3頭身）
- 頭の上に**小さな稲妻形の突起が1本**、ぴょこんと立っている
- 目はつぶらで、うれしそうに細めていてもよい。ほっぺに淡い赤み
- おなかにクリーム色の丸い面
- まわりに**小さな火花が数個**ふわっと浮かぶ
- 座っているか、短い足で立っている。どちらでもよい
- 印象: まだ力を出せていないが、体の中で電気がぱちぱちしている感じ

## 第2形態（`pikari-2.png`）

**すっと背が伸びて、二足で立つほそい体つき。**

- 3〜4頭身。手足が細く長くなり、走り出せそうな体つき
- 頭の稲妻の突起が**大きく鋭く**なり、後ろへ流れる
- 手の先が少しとがって、電気を帯びている
- 目に自信が出てくる。口は小さく笑っている
- おなかから胸にクリーム色の面（第1形態から続いている）
- まわりに**稲妻の線と火花**が数本
- 印象: 速さが本物になってきた。いつでも飛び出せる姿勢

## 第3形態（`pikari-3.png`）

**いちばん大きく、装飾がふえた完成形。**

- 4〜5頭身。しなやかで引き締まった体
- 頭から背中へ**稲妻の形をした帯・たてがみのようなもの**が数本、
  躍動的に伸びる（しずくの第3形態が水のリボンをまとっているのと同じ役割）
- 手足に電気の輪や火花のまとわりつき
- 目つきに落ち着いた強さ。やさしさは残す（子供向けなので睨まない）
- おなかから胸にクリーム色の面
- まわりに**稲妻・光の粒・きらめき**をやや多めに配置。
  ただしキャラのシルエットを潰さないこと
- 印象: 一瞬で間合いを詰める完成された速さ。かっこよさ寄りだが、まだ愛嬌がある

## 英語で渡す場合のキーワード（画像モデル向け）

```
cute kids' monster-collecting game character, electric type, vivid electric
yellow (#ffd23d), bold dark amber outline, cel shading with soft gradients and
glossy highlights, light from upper left, pale ivory cream belly patch, large
simple friendly eyes, gentle smile, small lightning bolt crest, sparks and
lightning motifs floating around, full body, front facing slightly angled,
centered with margin, clean vector-like game asset,
fully transparent background, no checkerboard pattern, no signature,
no watermark, no text, 2048x2048 square PNG
```

形態ごとに差し替える部分:

```
第1形態: tiny round chibi baby form, 2-3 heads tall, small crest, sitting or standing
第2形態: slim bipedal form, 3-4 heads tall, sharper swept-back crest, ready to dash
第3形態: larger final form, 4-5 heads tall, flowing lightning-shaped mane and ribbons
```

## 取り込み手順（画像が届いたあと）

```bash
node tools/prepare-art.js incoming-art/pikari-1.png js/img/pikari-0.png
```

3枚ぶん実行 → `js/svg/artManifest.js` に `pikari: [0, 1, 2]` を追加 →
`sw.js` の `ASSETS` に3ファイル追加して `CACHE_NAME` を上げる。

**注意**: 元画像が最初から透過済みなら `prepare-art.js` は背景除去を飛ばす
（`transparencyProfile` が判定する）。透過していない場合は縁からの塗りつぶしで
背景を落とすが、**キャラ内部の同系色まで消すことがある**ので、変換後に
透明率と輪郭を必ず確認する（`test/prepare-art.test.js` が機械検査する）。
